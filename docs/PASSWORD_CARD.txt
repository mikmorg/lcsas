TRANSCRIPTION CHECK CODE (optional but recommended)
  Code: __________   (4 hex characters)

  A hand-copied password discovered to have a typo DECADES LATER, at restore
  time, is an unrecoverable archive. The check code lets you (and later your
  heir) confirm the password was transcribed correctly without printing the
  password itself. To compute the code from your key file:

      python3 -c "import sys,hashlib;print(hashlib.sha256(open(sys.argv[1],'rb').read().rstrip(b'\n')).hexdigest()[:4])" KEYFILE

  Write the resulting 4 characters in the Code box above. To check a typed
  transcription later, run the same one-liner on the typed file (or use
  `lcsas key card --check <file> --code <code>`) and confirm it MATCHES.

  Security note: the code is the first 4 hex characters of
  SHA-256(password). It leaks ~16 bits of an oracle on the password —
  negligible against a high-entropy password, but stated honestly. Omit it
  if you prefer no disclosure at all.

  Tip: `lcsas --config lcsas.toml key card --repo <name>` generates this
  card with the check code already filled in (the password is never printed).

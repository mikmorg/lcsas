===== lcsas --help =====
usage: lcsas [-h] [--version] [--config CONFIG] [--db DB] [--verbose]
             [--lock-timeout LOCK_TIMEOUT]
             {init,repo,scan,pack,status,burn,stage,burn-iso,staging,location,copy,volume,catalog,restore,consolidate,verify,session,config,meta,recovery,key,estate}
             ...

Linux Cold Storage Archival Suite — orchestrates Rustic, Xorriso, and
DVDisaster for optical archival.

positional arguments:
  {init,repo,scan,pack,status,burn,stage,burn-iso,staging,location,copy,volume,catalog,restore,consolidate,verify,session,config,meta,recovery,key,estate}
                        Available commands
    init                Initialize the LCSAS catalog and config.
    repo                Manage backup repositories.
    scan                Scan mirrors for new packs and register them in the
                        catalog.
    pack                Manage individual packs in the catalog.
    status              Show archive status summary.
    burn                Burn staged ISOs to disc.
    stage               Stage ISOs for deferred burning.
    burn-iso            Burn a single ISO file (standalone, no catalog access
                        required).
    staging             Manage the staging area.
    location            Manage the locations where discs are kept.
    copy                Record the fate of a disc (deprecate/destroy).
    volume              Per-volume catalog queries.
    catalog             Catalog management.
    restore             Plan or execute a restore.
    consolidate         Merge volumes into a larger one.
    verify              Verify a volume's ISO or disc.
    session             Manage burn sessions.
    config              Configuration management.
    meta                Build a self-contained meta disc (recovery tools +
                        source).
    recovery            Build / verify the C89 + POSIX-sh recovery toolchain.
    key                 Split a repository password into SLIP-0039 shares, or
                        combine them.
    estate              Estate-planning artifacts (the whole-archive estate
                        card).

options:
  -h, --help            show this help message and exit
  --version             show program's version number and exit
  --config CONFIG       Path to TOML configuration file.
  --db DB               Path to SQLite archive catalog (overrides config).
  --verbose, -v         Show full tracebacks on errors.
  --lock-timeout LOCK_TIMEOUT
                        Seconds to wait for the catalog lock before failing
                        with exit code 75 (default: wait forever). Overrides
                        LCSAS_LOCK_TIMEOUT.

===== lcsas stage --help =====
usage: lcsas stage [-h] [--media MEDIA] [--for-location FOR_LOCATION]
                   [--repo [REPO ...]] [--collection NAME] [--min-fill PCT]
                   [--partial] [--clean] [--force] [--session SESSION]
                   [--dry-run] [--allow-escrow-drift] [--allow-low-redundancy]

options:
  -h, --help            show this help message and exit
  --media MEDIA         Media type (BD25, MDISC100, TEST_TINY, etc.).
  --for-location FOR_LOCATION
                        Stage only packs missing at this location.
  --repo [REPO ...]     Names of the repositories to stage (default: all).
  --collection NAME     Stage the [collections.NAME] of the config: its repos,
                        for its location (as --for-location), on its
                        media_type, with its min_fill_pct. Not with --repo,
                        --for-location or --media.
  --min-fill PCT        Do not stage a last volume whose packs fill less than
                        PCT% of its pack space (0-100); the full volumes
                        before it are staged. Overrides a collection's
                        min_fill_pct.
  --partial             Stage the last volume even if it is below the minimum
                        fill.
  --clean               Clean up staged ISOs for a session.
  --force               With --clean: also abort a never-burned session,
                        deleting its volumes and returning their packs to the
                        unarchived pool. A burned volume is never deleted.
  --session SESSION     Session ID (for --clean).
  --dry-run, -n         Show staging plan without creating ISOs or catalog
                        rows.
  --allow-escrow-drift  Proceed even if lcsas.toml's key_split/K/N disagrees
                        with the recorded split (KEY-08). Logged as a volume
                        event. For multi-config edge cases only — discs may
                        print share instructions that do not match the real
                        split.
  --allow-low-redundancy
                        Stage a volume even if its RS03 error correction would
                        be below the 5% floor, or its content exceeds the
                        medium's usable bytes. Recorded as a volume event. NOT
                        recommended.

Staging reads every selected pack in full and verifies its SHA-256 against the
catalog before mastering (corrupt mirror packs abort the stage). Expect one
extra full read of all staged data, e.g. ~14 minutes for 25 GB at 30 MB/s.
===== lcsas burn-iso --help =====
usage: lcsas burn-iso [-h] [--device DEVICE] [--verify | --no-verify]
                      [--verify-only] [--emit-receipt EMIT_RECEIPT]
                      [--label LABEL] [--location LOCATION]
                      [--session SESSION]
                      iso_path

Burn a single ISO to disc. Useful for split-machine workflows: stage on one
machine, transfer ISOs to a faster burner, then import the emitted receipts
back with 'catalog import-receipts'.

positional arguments:
  iso_path              Path to .iso file.

options:
  -h, --help            show this help message and exit
  --device DEVICE       Optical device path (overrides config; default
                        /dev/sr0 when neither is set).
  --verify, --no-verify
                        Verify after burning: read the disc back and compare
                        its SHA-256 with the ISO's (use --no-verify to skip).
  --verify-only         Do not burn: check the disc already in the drive
                        against the ISO, as --verify does, and write a receipt
                        for it (a lost receipt).
  --emit-receipt EMIT_RECEIPT
                        Write a burn receipt JSON for later catalog import. A
                        folder (existing, ending in a path separator, or a
                        name with no extension) gets <label>_<location>.json
                        and is created if missing; any other path is the file.
  --label LABEL         Volume label for the receipt. Defaults to the ISO's
                        parent directory name.
  --location LOCATION   Location tag for the receipt (required with --emit-
                        receipt).
  --session SESSION     Optional session ID to record in the receipt.

                        fails loud so the missing fast path is not a surprise.
  --allow-no-dvdisaster-source
                        Build even if the pinned dvdisaster RS03 source
                        tarball is absent from the recovery cache. Without
                        this flag the build fails loud, because
                        docs/DVDISASTER_RS03_FORMAT.md is only re-
                        implementable against the source it transcribes — that
                        source must travel on the meta disc. Run `sh
                        recovery/scripts/fetch_upstream.sh` to populate the
                        cache.
  --allow-incomplete    Permit a meta disc missing per-target binaries or root
                        restore artifacts (single-arch developer builds). By
                        default the build fails loud and lists every missing
                        artifact so an incomplete meta disc never ships
                        unnoticed (RST-05).
  --allow-missing-metadata
                        Permit a meta disc that carries no Rustic keys for a
                        live repository whose packs are on discs. By default
                        that fails the build (#437) — the disc could not
                        decrypt that repository. Deliberately separate from
                        --allow-incomplete, which means 'dev build lacking
                        per-target binaries': a habitual flag must not silence
                        a survivability gap. The acknowledgement is recorded
                        on the meta disc in volume_info.json.

===== lcsas key card --help =====
usage: lcsas key card [-h] [--repo REPO] [--out OUT] [--no-check-code]
                      [--check PASSWORD_FILE] [--code CODE]

options:
  -h, --help            show this help message and exit
  --repo REPO           Repository name the card is for (uses its configured
                        password_file name and creation context).
  --out OUT             Write the card here (default: stdout). The password is
                        never written — the owner fills the PASSWORD box by
                        hand.
  --no-check-code       Omit the transcription check code. The check code is
                        the first 4 hex chars of SHA-256(password); it leaks
                        ~16 bits of an oracle (negligible against a high-
                        entropy password) and lets an heir confirm they typed
                        the password correctly.
  --check PASSWORD_FILE
                        Check mode: recompute the check code from a typed-in
                        password file and print MATCH/MISMATCH against the
                        code on the card. Requires --code.
  --code CODE           The 4-char check code from a printed card, compared
                        against --check's password file. rc 0 on MATCH, 1 on
                        MISMATCH.

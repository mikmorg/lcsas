LCSAS RECOVERY -- NO WORKING OPERATING SYSTEM
==============================================

  +--------------------------------------------------------------+
  |  The LCSAS discs are NOT bootable.                           |
  |                                                              |
  |  Do not try to boot a computer from an LCSAS disc -- you     |
  |  will only get a "no bootable device" error.  If no          |
  |  computer with a working operating system is available,      |
  |  follow this page.                                           |
  +--------------------------------------------------------------+

You need a computer with a working operating system to read the
discs.  There are two ways to get one.

OPTION 1 -- USE ANY OTHER COMPUTER

Any working computer with an optical drive (internal or USB) can run
the recovery.  A friend's machine, a library computer, a second-hand
laptop -- anything running Windows, macOS, or Linux works.

Once you have one, go back to START_HERE.txt on this disc and follow
the section for that computer's operating system (Windows ->
restore.bat / RECOVER_WINDOWS.txt; macOS or Linux -> restore.sh /
RECOVER.txt).

OPTION 2 -- BOOT A LIVE-LINUX USB STICK ON THE DEAD MACHINE

If the machine in front of you has no working OS (dead disk, wiped
install, forgotten login) but otherwise powers on, you can run a
complete Linux system from a USB stick without installing anything.

You will need: any OTHER working computer (only for a few minutes,
to prepare the stick) and a USB stick of 8 GB or more.

  1. On any working machine, download a current mainstream Linux
     "live" desktop image.  Ubuntu Desktop LTS is the concrete
     example used here, but any current major Linux distribution
     works the same way.

  2. Write the image to the USB stick using the distribution's
     official instructions (search: "create Ubuntu live USB").
     The official tools run on Windows, macOS, and Linux.

  3. Plug the stick into the dead machine and power it on, pressing
     the boot-menu key at power-on (commonly F12, F2, Esc, or Del --
     the splash screen usually names it).  Pick the USB stick from
     the boot menu.

  4. When the live system asks, choose "Try Ubuntu" (run without
     installing).  You now have a full Linux desktop running from
     the stick.

  5. Insert the LCSAS META disc into the optical drive.  Most live
     systems mount it automatically when you click the disc icon in
     the file manager; otherwise, in a terminal:

         sudo mkdir -p /mnt
         sudo mount -o ro /dev/sr0 /mnt

  6. Run the recovery (in a terminal):

         sh /mnt/recovery/scripts/restore.sh /home/ubuntu/restored latest

     This prompts for the archive password and walks you through
     inserting data discs.  From here, RECOVER.txt on this disc is
     the full operator manual.

  7. Restored files land in /home/ubuntu/restored, which lives in
     RAM on a live system.  Copy them to a real disk (USB drive,
     internal disk) before powering off, or pass a path on a
     mounted disk as the target instead.

WHY THIS WORKS DECADES FROM NOW

A current live-Linux image is maintained by an OS vendor TODAY: it
is Secure-Boot signed, so modern firmware accepts it without BIOS
surgery, and it carries current hardware drivers, so it boots on
hardware that did not exist when these discs were burned.  The LCSAS
recovery tools themselves are static binaries that need nothing from
the host beyond a kernel -- the live system only has to boot and
mount the disc.  Always fetch a CURRENT image rather than archiving
one next to the discs: an old image rots against new hardware, a
current one never does.

WHAT IS ON THE DISC

The recovery medium bundles prebuilt static recovery binaries for
several architectures (recovery/bin/<arch>/), the complete C source
to rebuild them (recovery/src/), and plain-text documentation
(recovery/docs/).  It does not bundle an operating system, a C
compiler, or network tools.

HISTORICAL NOTE

Earlier revisions of this document described a bootable meta disc
(four-entry boot menu, bundled Linux/FreeBSD kernels, and a build
flag that never existed in the CLI).  That boot stack was never
built and no LCSAS disc was ever bootable; the scaffolding was
dropped in 2026 and quarantined to experimental/boot/ in the LCSAS
source repository.
